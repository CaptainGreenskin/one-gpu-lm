# 042 · 首次改码示范微调

用固定版本的 Qwen/Qwen3.8-27B 初始化一个 LoRA 候选。在 031 的 1,006 条动作记录上加入 041 审计通过的 27 条示范，覆盖 9 道题、5 个训练仓库家族。每道题保留已执行的首次编辑、单独运行的回归验证和显式提交。同一题两组均有合格示范时，按 041 的预注册规则保留关闭思考组的记录。 [041 曲线和匿名配对结果](../041-first-edit-continuation/results/2026-11-21)

沿用 031 的 BF16、LoRA rank 8、alpha 16、AdamW、学习率 1e-5 和种子 101。保留 031 动作的相对顺序，新增记录分散到 27 个不同的梯度累积窗口。仍运行 126 次优化器更新，监督 token 从 63,991 增至 66,440，完整输入增至 2,465,490 token。训练只监督工具动作，审计时核对所有输入、更新记录和权重保存重载后的贪心生成 ID。 [训练配方](../031-correction-mix/cycle-spec.json) · [冻结回执](registration.json)

训练审计通过后，在六个独立仓库家族的 60 道开发题上将该候选与同一底座成对比较，每题重复三轮。两组使用相同推理流程和相同上限，每题最多 12 次调用、6,144 个生成 token。成功需要实际改码、通过独立评分并在预算内提交。进入最终测试须同时满足完整审计、成功率至少提高 10 个百分点、配对 95% 区间下界大于零、各仓库家族下降至多 10 个百分点。 [开发验收门槛](../039-release-development/design.json)
