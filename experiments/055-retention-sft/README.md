# 055 · 降低学习率与底座能力保留

054 的 180 个开发配对中，底座通过而 LoRA 退步 6 次，集中在 3 道题。其中 5 次已经修改源码，仍未修对。另一次修对后没有提交。055 测试减小更新步长能否保住这些任务，同时保留 054 的增益。[054 开发对照](../054-expanded-repair-sft/results/2026-11-26-development/) · [054 最终结果](../054-expanded-repair-sft/results/2026-11-26-final/)

从同一固定版本的 27B 底座初始化 LoRA。沿用 394 条经执行验证的训练动作、79 个修复案例、样本顺序、监督标签、50 次更新和训练种子。将 AdamW 学习率从 `1e-5` 降至 `5e-6`。[训练设计](design.json) · [训练登记](training-registration.json) · [训练与审计入口](train.py)

训练前固定了 9 道旧开发题，涵盖 3 道退步题、3 道稳定增益题和 3 道底座与 054 均通过的题。用同一推理流程、预算和三轮复跑诊断改动。完整开发验收另选独立仓库家族，通过后再启用独立封存的最终测试与原发布门槛。
