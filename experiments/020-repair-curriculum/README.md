019 的低学习率候选从 6/15 提高到 7/15，但退步两道；高学习率只有 1/15。020 继续使用相同底座、任务划分、推理预算和质量门槛，先检查数据改进是否有效。48 道最终任务及附加函数回归只在开发集选出合格候选后打开。

## 已完成的诊断

- [数值复盘](diagnosis/019-numeric/)：修复只占六分之一更新，但占约 42.2% 监督 token；不能把问题简单归结为修复 token 太少。原示范在第 3 次调用修复，缺少未编辑进度提醒及失败后纠错状态。
- [命令级核查](diagnosis/019-trace-review.json)：高学习率的六道退步没有工具格式错误，实际出现空读取、失败补丁、无效果补丁和重复探测。低学习率的两道退步分别涉及错误实现后无效重试，以及 `sed` 替换中的 `&` 扩展导致源码损坏。
- “没有观察到源码修改”不等于“没有尝试修改”。这些是执行层面的观测，不能证明某一种 SFT 退步机制。原始命令、源码差异和开发题答案保持私有，不能用于训练。
- [本地动作长度检查](diagnosis/static-target-lengths.json)：55 道训练题的最长目标为 411 tokens，低于 512 上限；[tokenizer 身份](diagnosis/static-tokenizer-identity.json)已核对固定版本元数据。这没有执行真实任务，也没有检查包含完整工具输出的上下文，不能替代 Linux 准入。

## 已通过数据准入的配对设计

| 配置 | repair | recovery |
| --- | --- | --- |
| 初始化 | 同一固定底座，全新 LoRA | 同一固定底座，全新 LoRA |
| 学习率、rank、seed | 2e-6、8、101 | 相同 |
| 训练任务、更新次数 | 原 55 道训练题，330 次 | 相同 |
| 共同记录 | 275 条：定位、修复、验证、提交、停滞后修复 | 完全相同 |
| 对照记录 | 55 条普通观察后的修复 | 55 条执行失败或错误修改后测试失败的纠正 |
| 每题推理上限 | 12 次调用、每次 512 / 总计 6,144 生成 token | 相同 |

两组都采用实际源码定位和带唯一匹配断言的 Python 字面替换，避免直接猜测行号以及 shell 替换扩展。候选只在最后 55 个样本位置改变上下文与必要的纠正目标：预定 28 个匹配断言失败、27 个错误修改后的测试失败。错误操作只是上下文，不能成为监督目标。每条保留修复都必须经过独立工作区判分；失败状态也需有实际执行证据。

这里比较的是相同更新次数和上限预算，实际输入、监督 token 与卡时分别报告，不宣称严格等 token 或等 FLOPs。开发集已多次被观察，其成绩只能用于选择；后续独立验收依赖只在开发阶段合格后打开的最终任务。

[训练前规则](preparation-plan.json)已在真实数据准入后锁定。最多两个候选，训练加评测总 GPU 墙钟上限 12 小时。两组均使用原 019 的低学习率配置，不加载 019 候选继续训练。开发集要求净增至少 1 道且最多退步 1 道；最终发布门槛沿用 019，不因结果不好而降低。

## 可复用入口

- [配对轨迹生成器](../../one_gpu_lm/data/repair_curriculum.py)：只接受已准入的训练分区和来源许可，执行实际观察、错误尝试、测试与纠正。
- [数据验收](preparation.py)：重建允许的源码状态变化，核对每条监督目标与真实历史，并验证 275 条相同 / 55 条差异记录。
- [有预算的运行控制器](run.py)、[选择门槛](decision.py)、[冻结工具](freeze.py)：没有完成冻结、公开核验和成功 CI 时不能启动训练。
- [执行审计](audit.py)、[参数与内容检查](postrun_integrity.py)：实验结束后再核验实际请求、源码、参数和最终测试封存状态。
- [报告生成器](report.py)：分别核对两组实际 token 暴露、共同样本与差异样本、逐题配对和发布门槛，再生成训练曲线、成功率图及结果表；缺失或不一致的证据不能生成合格结果。

事后处理还核对附加 9 道函数检查的实际输入 token 哈希、任务顺序、预算和底座/适配器标记，并绑定私有生成文件与公开结果文件的哈希。这项核验在本轮运行期间补充，只读取已有证据，不重新生成或评分；运行脚本、训练样本、选择规则和质量门槛仍使用原先冻结版本。事后处理脚本的哈希分别保存在完整性回执与最终报告中。

更换自己的任务时，需要提供有权使用的源码快照、已验证的任务控制和仅来自训练任务的错误尝试计划。未经执行的草案不能当成训练样本；本地合成夹具的单元测试也不能当成这轮实验成绩。原始源码许可保留在 [notices](notices/)，不会被本项目 MIT 许可覆盖。
