# 首批非确定性测量：数值审计失败后中止

运行代码固定于 [da00d64](https://github.com/CaptainGreenskin/one-gpu-lm/tree/da00d6481a4c3176552d811b4c6c2588882dae95/experiments/010-7b-context-scaling)。已完成 13 个进程，第 14 个进程在审计失败后由我们中止。原始指标、当时的协议、源码哈希、硬件采样及 `audit.json` 保留在本目录。`status.json` 是中止前的最后状态，`campaign.json` 标记了中止原因。

已完成的 6 对中，4 对超过预设的 loss 绝对差 0.001；最大差为 0.00234985。首步损失相同，更新后出现差异，输入与初始参数采样哈希一致。所有进程本身都完成了更新并检查了有限梯度，失败发生在配对的数值一致性门禁。

后续复测仅将确定性算法设为 True，继续固定 CUBLAS 工作区，原有损失与梯度容差不变。整批旧测量均排除在正式性能曲线之外，避免把不同 kernel 设置的记录混合。首批硬件采样覆盖 UTC 03:28:40 至 03:30:10；它不含可靠的进程终止时间，因此不宣称这是精确起止时长。
