# 本次运行的来源与边界

正式 GPU 测量代码：[583ec7f](https://github.com/CaptainGreenskin/one-gpu-lm/tree/583ec7f/experiments/010-7b-context-scaling)。`sources.json` 中所有文件的 SHA-256 已逐项与这个提交核对。之后仅完善报告生成和说明文档，没有改写训练指标。

正式运行在北京时间 2026-11-09 11:30:53 至 11:36:48 完成，整组耗时 354.47 秒，包含初始化、48 个独立进程及进程间隙。每个进程 2 步热身、6 步计时，共 384 次完整更新，其中 288 次计时。每对开启/关闭重算的输入与初始参数采样哈希一致，8 步 loss 及梯度范数逐项相同；另有小模型 CPU 测试逐参数比较梯度和更新结果。范数相同本身不等于对 7B 的每一个梯度元素做了逐位比较。

设备为 NVIDIA RTX PRO 6000 Blackwell Workstation Edition，单卡；Python 3.10.12、PyTorch 2.14.1+cu130、CUDA 构建 13.0、驱动 595.99.02。正式测量前设备空闲，174 个设备采样的最高温度为 64 °C、最高功率为 552.42 W。设备采样峰值总显存为 40,763 MiB，包括缓存分配器保留及驱动占用，不与表中的 PyTorch allocated 混用。全部进程完成后设备恢复空闲。

全参数模式更新 7,028,273,152 个可训练参数，使用 BF16 权重/梯度及 Adafactor；LoRA 冻结 BF16 主干，仅训练 4,194,304 个 FP32 适配器参数，使用 AdamW。主干未量化，因此不是 QLoRA。全部输入均为合成 token，权重随机初始化，未验证长期收敛，也没有真实语料质量分数。

[首批中止记录](aborted-nondeterministic/) 与正式复测分开保存。没有放宽数值容差，也没有把不同确定性设置的测量混合计算中位数。
