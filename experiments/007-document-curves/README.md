# 007 · 换一份中文技术语料，BPE 会在第几遍开始过拟合？

复验对象是 Vue 官方中文指南和 API 文档。固定上游版本，保留这两个栏目中至少 512 字节的 Markdown 页面，按栏目分别以相对路径的 SHA-256 排序，序号从零算起，每四篇取第一篇留作验证。风格指南的候选页面为英文，未纳入。按完整文件划分后有 60 篇训练文档（679,992 字节）和 20 篇验证文档（187,227 字节）。训练规模比 006 的 Rust 文本小 4.9%。保留 Markdown、代码示例和标记，统一 UTF-8 文本的换行、NFC 和文件首尾空白。语料署名 Yuxi (Evan) You 与 Vue 文档贡献者，所选文档采用 CC BY 4.0。下载脚本保留上游许可。[上游固定版本](https://github.com/vuejs-translations/docs-zh-cn/tree/9f4cd576000707fe65ec600fb154724951dcdfd0) · [许可](https://github.com/vuejs-translations/docs-zh-cn/blob/9f4cd576000707fe65ec600fb154724951dcdfd0/LICENSE) · [文件划分与 SHA-256](source-files.json)

训练前固定判据。种子 42、43、44 各从零训练 24 遍，沿用 006 的 85.6M 参数 GPT、冻结的 2,048 项 BPE 词表、AdamW 学习率 0.0003、每批至多 8 个片段、384 原文字节上下文。每遍末用同一组权重评估完整训练与验证集。先算每遍的三种子平均，再找验证最低点，取最低点后首次连续两遍“验证比前一遍变差、训练比前一遍改善”的第一遍作为过拟合起点。最低点、首次回升、持续分叉起点分开报告，逐种子也使用同一规则。主比较是 Vue 平均曲线的持续分叉起点是否落在第 8～10 遍，并与 Rust 的均值起点第 9 遍对照。不同语料的绝对分数和每遍更新数单独列示。[006 的规则和原始曲线](../006-bpe-epoch-curve/)
