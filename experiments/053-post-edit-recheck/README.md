# 053 · 改码后的失败回归与纠错

052 的 LoRA 有 21 次改码后仍未修对。这 21 次都用尽了 12 次调用，改码后均未运行任务指定的回归命令。052 的训练示范中，10 次中途运行失败回归的动作只作为后续修改的上下文。053 将这 10 次已执行的回归动作还原成监督目标。 [052 开发结果](../052-grounded-first-edit/results/2026-11-24-development/)

在另 30 条已通过独立评分的训练示范上，于首次修改后运行同一个回归命令，再完成其余修改、复测和提交。15 条经过失败回归后修对，原始失败反馈确实进入了下一次修改的输入。13 条的中间补丁已通过回归，另 2 条的失败未达到语义失败准入条件。这些轨迹来自普通代码修复的训练题，全部在离线 CPU 沙箱内执行。 [数据与验收规则](design.json)
