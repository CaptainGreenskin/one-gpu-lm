Successful baseline trajectories are self-generated local supervision, not outputs purchased from a teacher API. They include successful inspection/test commands and repairs from tasks that passed independent grading; each record is not necessarily a new repair demonstration. Failed training tasks may contribute separately labeled, executed reference repairs from their authorized snapshots, but the selected kind counts determine whether any actually entered training. Only the current assistant response contributes to loss.

Task controls admitted 36 of 40 constructed tasks. Frozen counts: `{"dev": 8, "test": 7, "train": 21}`. Training, development and final tasks use different repositories and API families; no development/test answers or trajectories enter SFT. This separation does not prove absence from base-model pretraining, nor does it make a 7-task final sample representative.

Public upstream tests are visible. Independent final grading reconstructs a fresh task and submits allowed source files only; it does not introduce new hidden assertions. Rejected tasks and excluded timing/thread-stress tests remain disclosed. The invalidated interface probe supplies no supervision.

The provenance records preserve repository revisions, file/license hashes and required notices. The project MIT license does not replace third-party source terms. Hashes cannot recreate withheld content: contributors can use the public input contract to evaluate their own authorized repositories, while exact reproduction of this private dataset needs the corresponding source preparation and task specifications.
