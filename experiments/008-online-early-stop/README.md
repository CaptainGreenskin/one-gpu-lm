# 008 · 用实时早停规则和独立测试文档比较训练预算

006、007 在训练结束后回看整条验证曲线。008 在任何测试评分前固定以下规则，用未参与前两次实验的种子从零训练，记录实际停机时间，并在所有选择锁定后打开测试集。

- **早停。** 每遍结束评估全部验证文本。第 1 遍建立记录。只有验证 bits/原文字节严格低于历史最低值才保存当前权重并把等待次数清零，持平也算一次未改善。连续两遍未改善就立即停止更新，最迟第 24 遍停止。交付迄今验证分数最低的权重；并列保留更早的一遍。每个种子独立决定。已训练遍数包含等待的两遍。
- **对照。** 固定 8 遍是依据历史 Rust、Vue 结果选择的强基线，固定 24 遍是较长预算。两者均直接交付最后一遍。三种策略各自启动并结束训练进程，固定策略在训练中跳过验证。每份语料用新种子 101、102、103，在同一卡上顺序执行 3 × 3 次。每个种子内轮换策略顺序。沿用之前的训练与验证文本、冻结 BPE、85.6M 参数 GPT、批大小、BF16 和 AdamW，全部策略使用同一确定性设置。
- **卡时。** 一张卡上，主指标从父进程启动训练子进程计至其正常退出，包括初始化、更新、策略实际需要的验证和权重保存。另记更新循环时间。每个配对按“固定用时 − 早停用时”计节省；比例用三种子的总时间计算。独立测试评分、数据准备、一次性硬件预检单列，不计入部署某个训练策略的耗时。
- **测试。** 对同一固定版本的 Rust 书选第 01、02、03、04、05、07 技术附录，同一固定版本的 Vue 选交互教程第 1～15 课的说明文档。按整篇排除在训练和验证之外，保持 006/007 的原划分。两套测试都是新的文档类型。按原始 UTF-8 字节加权，在同一组测试片段上比较选定权重。排除与训练或验证完全相同的固定边界片段，记录排除量。全部 18 项训练的选择与模型哈希先锁定，之后才对三个策略评分。每份权重只评价其自身语料的测试文档，按文档另列分数。
- **结果判据。** 测试差定义为“早停 − 固定”的 bits/字节，正数为变差。分别报告两种基线、两套语料的配对差、均值和范围。预先选定 +0.05 bits/字节为实用容忍上限（对应按字节计算的困惑度约 +3.5%）。仅当某语料对某基线的三个种子都不超过此上限，才称该组“观察到的退化均在容忍范围内”。另报实际数值升降。三个种子和有限文档支持描述性结论。
