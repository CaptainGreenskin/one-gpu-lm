# 003 · 训练 100 步与 1,000 步的差别

在同一张 RTX PRO 6000 和同一份中文维基语料上，从随机初始化训练 1,000 步，每个种子在第 100 步留下一份权重。比较同一条训练轨迹的两组权重。三个种子为 42、43、44。结构、数据切分、每步 4,096 字节、学习率和优化器沿用 [实验 002](../002-first-train/)。

**评价方法。** 使用全部 256 篇验证文章。每篇第一个字节没有上文，两个文章分隔换行也不参与计分。其余每个目标字节恰好计分一次。模型上下文为 512 字节，每次最多计分 256 个连续目标，以窗口末端对齐回看上下文。总 bits/byte 按目标字节数加权，同时输出逐篇结果。这个指标与 002 的 8 个抽样批次含义不同。

**运行。** 按 002 准备 PyTorch CUDA 环境和数据，在仓库根目录运行。输出目录必须是新目录。每个种子会保存两份模型和两份完整验证报告。短测期间卡上可能有其他任务，训练计时排除中间权重写盘、验证和环境准备。

```bash
CUDA_VISIBLE_DEVICES=0 OMP_NUM_THREADS=2 bash experiments/003-training-budget/run.sh runs/budget-v1
```

比较每个种子全量验证 bits/byte 的差值、改善的文章数以及后 900 步耗时。第 100 步处理 409,600 个训练字节，第 1,000 步累计处理 4,096,000 个。数据按原训练器随机抽取，累计处理字节可能重复。
