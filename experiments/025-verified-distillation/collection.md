# 025 正式轨迹采集预登记

目标是在固定预算内，从 164 道 CPU 准入通过的训练题取得至少 100 条真实执行、独立判定通过的完整轨迹，为唯一学生候选提供监督。它是本地底座的高预算自蒸馏，不使用外部教师 API，也不预先声称模型能力提高。

训练池有 5 个仓库家族、77 道 Python / 87 道 JavaScript 题。其中 12 道曾用于采集校准，其余 152 道没有教师生成记录；旧轨迹不并入这次训练集。166 个作者构造的候选中，2 个未造成可验证行为故障，在模型采集前排除。合并池重新执行了全部 CPU 准入，164/164 通过。它们是短小的受控故障，不是历史 issue 或通用编码能力基准。

任务按仓库轮转，仓库内以固定字符串与任务 ID 的 SHA-256 排序，完整顺序写入协议。每题最多一次尝试、24 次调用、每次 512 个生成 token、总计 12,288 个生成 token、8,192 个输入 token、900 秒，单次工具 60 秒。流水线最多 12 小时，监督进程另有 30 秒收尾宽限。不会为了凑足成功数重复尝试或延长。

使用已公开校准的提交验证规则：模型必须自己执行完整的独立回归命令，通过后再提交。规则不会替模型执行测试，也不访问隐藏检查。未执行的提交拒绝计入调用与 token 成本，保留在历史中，但不作为正向动作目标。

每条合格轨迹必须有实际源文件修改、当前代码上的独立回归通过、明确提交和隔离判定通过。全部实际请求需要逐 token 重放验证；任何有效执行动作无法完整编码时，排除整条轨迹，不截断目标或只取成功末尾。动作记录数与完整轨迹数分别报告。失败、无修改、格式错误、超限、未运行项及未知生成消耗均保留。

准入门槛是至少 100 条完整轨迹、每个训练仓库至少 5 条、覆盖两种语言、164 道均完成且无未核算生成。未达门槛不启动学生训练。采集完成后只做 tokenizer 审计与私有数据导出，不自动更新参数。

[后续科学规则](cycle-spec.json)同时登记唯一候选配方、四臂预算和开发达标条件。训练器和评测器的可执行版本仍须在各自执行前单独冻结并通过检查；新开发集此时为 0 次模型评分。既有最终测试继续封存，本轮开发成绩不触发参数发布。

公开代码、来源元数据、许可声明、校验回执、成本和曲线；原始任务、源代码副本、轨迹、机器连接信息和权重保留私有。此前失败试跑、校准与容量检查仍以各自预登记提交复现。

公开读者可以复用执行流程、核对回执；因为任务规格保留私有，仅凭公开材料无法逐题重现本次成绩。来源授权与哈希审计也不能证明底座预训练时从未见过这些开源项目。
