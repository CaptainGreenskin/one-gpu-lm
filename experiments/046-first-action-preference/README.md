# 046 · 首次动作的偏好微调

候选从固定版本的 Qwen3.8-27B 初始化 rank 8 LoRA。用直接偏好优化（DPO）比较 045 中在同一恢复状态下执行的两种首个动作。通过独立测试、单独运行回归并完成提交的一支提供首选动作。两支共用的 tokenizer 前缀保持一致，损失只计算动作序列。 [045 采集规则](../045-first-action-forks/)

训练入口要求两支都已经跑完并通过全量审计，核对原有生成回执、token 前缀、剩余预算和来源清单，再从实际入选样本冻结训练顺序。底座权重冻结，参考分数通过临时禁用 LoRA 获得。配方使用一遍训练、每四对一次更新和 β=0.1，每次更新保存适配器、优化器及随机数状态。 [训练入口](../../one_gpu_lm/verified/decision_training.py) · [样本核验](../../one_gpu_lm/verified/decision_training_data.py)

工作站 CPU 预检用生产 tokenizer 对上 22 个已登记训练状态的实际输入 token，并验证了缺少完整采集审计时的拒绝路径。优化器与恢复流程的测试使用小 Qwen 实例。正式训练的样本数和实际收益以完整审计及后续同预算的独立开发对照为准。 [既定发布验收](../../docs/modelscope-release.md)
