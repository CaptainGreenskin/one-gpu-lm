# 021 CPU 准备记录

所有调整发生在首次模型采集、参数更新和评分之前。模型任务分数未参与选择。

- 新仓库固定为 toolz、cachetools、Mistune、marshmallow，六题/仓库，均为缺失实现的构造任务。
- 为兼容隔离环境的 Python 3.10，cachetools、Mistune、marshmallow 在准入前固定为公开兼容版本；具体提交、许可和所用文件哈希见 sources.json。未采用 npm/node-semver，避免为新队列引入另一套 Node 测试依赖与参考副本暴露面；不声称实际检测到该仓库泄漏。
- 新队列使用独立 Python 依赖目录，固定安装 simplejson 3.20.1。历史队列的源码、测试和依赖完整内容保持不变，实际快照在 Linux 上核验。
- 首次 CPU 检查 24 题中 22 题通过；两个 Mistune 缺陷导致大批失败输出而触发输出限制。统一把该仓库测试命令改为短 traceback、最多报告十个失败，成功仍须跑完全部测试。任务、缺陷和测试范围未改变。原失败回执保留，第二次 24/24 通过；缺陷均以测试退出码 1 失败，恢复后退出码 0。
- 四个新仓库均在实际隔离沙箱执行参考暴露扫描，通过包名副本、选中文件哈希和可见归档检查。它不是语义相似性检查，也不是预训练去污染证明。
- 使用脚本固定回应做了一次 CPU 传输自检：完整保存八次真实工具执行后的状态，代理仍看到十二次调用额度；无模型生成。该自检标为不可用训练数据，独立目录不会进入采集器。
- 数据构造会拒绝存在受保护文件变化、缺失状态、后端错误、非法源码或不完整历史的前缀；完整输入或目标超长时按固定顺序检查下一个状态。没有合格状态时保留准确旧样本，不截断、不补造历史。

总预算从真正的模型流水线开始计时。数据生成、公开回执等待、训练和评测都在同一次十二小时截止内。CPU 准备不计入 GPU 实验时长，报告分别披露。
