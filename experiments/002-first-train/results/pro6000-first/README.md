# 100 步中文 GPT 单卡实测

2026-11-04，在一张 RTX PRO 6000 Blackwell Workstation Edition 上从随机权重训练了 85,645,824 参数的字节级 GPT。源代码版本为 `b5c1106`，随机种子 42。输入是固定版本的中文维基百科，按文章划分训练集与验证集。[训练指标](train-metrics.json) · [语料校验值](../../wiki-zh-reference.json)

| 指标 | 本次实测 |
| --- | ---: |
| 更新步数 / 训练字节数 | 100 / 409,600 |
| 训练更新耗时 | 4.376 秒 |
| 吞吐 | 93,604 字节/秒 |
| PyTorch 峰值已分配显存 | 2.571 GiB |
| 验证 bits/byte，训练前 → 后 | 8.106 → 5.386 |

训练循环保留首步开销，排除了验证、写盘和进程启动的时间。验证使用同一组位置上的 8 个批次，共 32,768 个目标字节。这个数值用于日后同口径回归。本轮做了一次测量，不能据此估计结果的波动。[原始摘要](summary.json)

卡上已有进程在启动前占用约 47 GiB 显存，三次采样时 GPU 利用率均为 0%。实测使用工作站已有的 Python 3.10.12、PyTorch 2.14.1+cu130、CUDA 13.0 构建和 595.99.02 驱动。运行设置为 `CUDA_VISIBLE_DEVICES=0`、`OMP_NUM_THREADS=2`。BF16 因果注意力反向传播通过，然后执行 12 步 GPU 冒烟测试和 100 步校准。[环境记录](environment.json) · [硬件记录](hardware.csv) · [GPU 冒烟测试](smoke-metrics.json)

最终 checkpoint 为 342,624,035 字节。验收程序读取了模型配置和嵌入权重，随后在 CPU 上严格载入全部权重，以“一张显卡”的 12 个 UTF-8 字节完成前向计算，返回的 3,072 个 logits 均为有限值。权重保存在工作站，文件的 SHA-256 和前向验证结果可用于核对。[权重验证记录](checkpoint-check.json)
