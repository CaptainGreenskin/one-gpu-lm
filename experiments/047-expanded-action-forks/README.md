# 047 · 扩大同一状态的首次动作配对

045 在 22 个训练状态上得到 5 对通过审计的偏好样本。047 纳入另外 129 个训练任务的复放状态，覆盖五个训练仓库家族。每个状态已核对保护文件、剩余调用和 token 预算，以及固定版本 Qwen3.8-27B 的实际输入 token。 [045 结果](../045-first-action-forks/results/2026-11-22/) · [预登记和预算](registration.json)

每对从同一工作区与对话开始。贪心组沿用贪心解码，采样组只在第一步使用温度 0.7、top-p 0.9 和按全局序号固定的种子。两组使用相同的模型、工具、回归命令和剩余预算。六个批次按预先固定的顺序运行，共 258 次尝试，每批完成后审计。

独立评分、重新运行回归检查和实际提交均通过，才计为修复成功。两组首个命令均实际执行、命令相异、成功结果相反且 token 前缀一致，才可进入偏好样本池。报告统计完整配对、失败类别、请求回执和硬件测量。

训练工作站可用 `run.py freeze` 校验原始审计和复放工作区并固定六个批次。登记通过公开读回和 CI 后，用 `run.py campaign --publication <核验回执>` 执行，两个入口都用 `--root <训练目录> --plan <登记文件>` 指定输入。原始轨迹和生成回执保存在私有工作区。 [实验设计](design.json) · [执行入口](run.py)
