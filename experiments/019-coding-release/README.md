## 可复用实现

- [训练与推理共用的前缀编码](../../one_gpu_lm/common/tokenization.py)与[assistant-only 训练编码](../../one_gpu_lm/common/training_encoding.py)：验证完整训练序列确实延续实际生成前缀，边界不一致直接失败。
- [可执行参考修复示范](../../one_gpu_lm/data/reference_episodes.py)：只处理 train 分区，依次检查源码、复现失败、应用修复、复查、单独执行回归及提交；执行结果进入原生工具历史，最终源码在新工作区独立判分。
- [有上限的均衡选择](../../one_gpu_lm/data/balanced.py)：`--up-to` 只选真实存在的合格记录，不为填满步数重复样本；原生格式按模型可见的 token 序列去重。
- [实际准备产物验收](preparation.py)：重新核对任务分区、干净/缺陷/恢复控制、完整修复目标覆盖、真实 token 统计和逐条执行历史；测试收集失败不能作为合格缺陷。
- [开发集选择与发布门槛](decision.py)、[两候选控制器](run.py)：实际任务清单、数据准入、记录数量和文件哈希须冻结为 `protocol.json`，并完成公开核验后才允许运行。
- [实际产物冻结](freeze.py)：必须先完成执行验收和数据筛选；记录数据、依赖、源码、配置及框架版本证据。训练控制器还要求同一份协议的公开文件核验与成功 CI 回执，检查通过后才开始原定的 12 小时预算。

[来源登记](sources.json)记录固定版本和许可审查，实际任务准入见[执行验收](preflight/admission.json)。[训练来源的原始许可](notices/)独立保留，不被本项目 MIT 许可替代。候选训练数据和评测任务均不随代码仓库发布。

### 冻结前草案范围

拟准入 56 个训练任务、15 个开发任务、24 个历史回归任务和 24 个新仓库任务。最终以冻结前完成的准入与数据筛选回执为准；任何排除均保留原因，不能根据模型成绩换题。训练数据至少覆盖 48 个合格任务、4 个仓库、160 条唯一记录和 16,384 个监督 token。最终每个被计入覆盖率的任务必须包含可用的修复目标，不能仅靠阅读命令凑覆盖率。

这是一轮小规模训练与发布验证。明确的收益门槛用于决定是否值得发布实验性 adapter，并不预先保证能通过。未完成的试验和未通过的候选不会标记为“训练好了”。

[本地固定 tokenizer 长度检查](preflight/target-lengths-local.json)覆盖拟训练的 56 个任务：所有六步示范的目标分别不超过 512 token，若全部保留则共有 22,259 个监督 token。此检查未执行命令，也没有真实工具输出形成的完整上下文，**不能替代 Linux 数据准入与训练数据验收**。正式训练前的 `preparation.py` 会重新编码实际数据，并核对每一条监督目标和前缀都来自对应的已执行、独立判分通过的示范。

### 实际数据验收

最终为 55 个训练任务、15 个开发任务、24 个历史回归任务和 24 个新仓库任务；118 项任务的干净、缺陷、恢复控制均通过。SemVer 构造函数因测试收集失败在冻结前排除，记录见[任务排除](preflight/task-exclusions.json)。四个新仓库的[最终参考扫描](preflight/reference-screen-final.json)通过，仍保留扫描范围和不可读条目的限制。

55 个训练任务全部执行六步参考修复，并在独立工作区判分通过。最终 330 条唯一记录、475,778 个输入 token、21,760 个监督 token；最大完整上下文 2,913 token、最大目标 382 token，没有因长度排除记录。每个任务保留了完整修复目标。[实际验收](preflight/preparation-verified.json)、[数据筛选](preflight/data-selection.json)、[Linux 检查](preflight/linux-checks.json)、[输入与许可记录检查](preflight/training-input-audit.json)均为执行后产物，不代表模型能力成绩。

两个候选各执行一次相同数据遍历、330 次更新，仅学习率不同。[训练完成回执](preflight/training-completed.json)记录两组各 58,363,904 个可训练参数、约 502/503 秒更新耗时、相同的采样顺序及保存重载一致性。权重更新和开发集评测均已完成，质量门槛未通过；这不是全参数预训练或编码能力提升的证明。

冻结时间为 2026-11-11 14:07:12 UTC（北京时间 22:07:12）；记录 97 个实际输入文件的哈希。冻结前没有启动 019 权重训练或模型任务评分。[冻结时复验](preflight/freeze-verified.json)再次核对了实际数据。
