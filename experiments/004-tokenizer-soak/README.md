# 004 · 单卡八小时分词与稳定性测试

相同单卡训练时间内，中文 BPE 与逐字节模型在同一段留出文本上分别需要多少比特？在 8 小时窗口内交替运行独立训练、完整验证和硬件采样。每项任务从随机权重开始。运行窗口从 BF16 预检通过后计时，使用 UTC 绝对截止时间；到期时中断未结束的试验，只纳入两侧均正常完成的配对。

**语料和指标。** 沿用 002 的训练/验证文章，按完整字符切成不超过 384 个原始 UTF-8 字节的片段。训练用同种子的片段采样流，较快的一组可以在同一预算内处理更多片段。每段重新加入起始标记。验证对全部 256 篇文章的 986,031 个正文字节评分，排除文间分隔符，包括各段首字节。将规范分词序列的负对数概率除以原始字节数，以 bits/byte 表示。BPE 对应单一规范切分，这个分数不是对所有等价切分求和得到的原文边际概率。实验 003 的上下文规则不同，请在本实验内比较两组。

**控制条件。** 两组均为 12 层、宽 768、12 个注意力头，使用绑定的输入输出嵌入、AdamW 与 BF16。逐字节词表含 BOS 共 257 项、前馈层宽度 3072；BPE 含 BOS 共 2049 项、前馈层宽度 3000，使总参数量接近。两组每步取 8 个原文片段，动态补齐到该批最大 token 数。准备语料、建模、验证和写盘在短任务预算外，这些活动都计入整个八小时窗口。

**预算与顺序。** 先对种子 42、43、44 分别运行 45、300、1200 和 2400 秒两组实验，在相邻配对间交替顺序。剩余时间继续以 300 秒预算配对测试新种子。每个训练步同步 GPU；实际训练时间可能超过该项预算一个更新步。每 30 秒采样显存、利用率、温度、功耗、SM 时钟。运行日志记录失败和重试；只有正常产生有限验证结果的试验才能进入配对分析。训练权重保留在工作站。

**重现。** 在仓库根目录，用实验 002 的 PyTorch CUDA 环境和已验证的中文维基语料运行：

```bash
python -m pip install tokenizers==0.21.4
python experiments/004-tokenizer-soak/prepare.py
CUDA_VISIBLE_DEVICES=0 OMP_NUM_THREADS=2 python experiments/004-tokenizer-soak/campaign.py --out runs/soak8
```

同一路径重启将沿用原始截止时刻，并跳过已完成的试验。准备脚本验证原料、逐片段检查编码可逆性，运行器验证编码缓存的 SHA-256。冻结的词表由训练文章拟合，词表数据随中文维基来源按 CC BY-SA 3.0 分享；原创程序沿用仓库的 MIT 许可。[语料来源](../002-first-train/README.md#本次中文语料) · [固定清单](prepared-reference.json)
